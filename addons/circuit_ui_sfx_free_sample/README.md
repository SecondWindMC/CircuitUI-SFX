# Circuit UI SFX Free Sample

12 procedural retro/arcade game sound effects for Godot projects, game jams, prototypes, pixel-art games, and 8-bit/chiptune-style projects.

The WAV files are in `audio/`. They are released under CC0 1.0; see `LICENSE`.

Project page and previews: https://secondwindmc.github.io/circuit-ui-sfx.html
